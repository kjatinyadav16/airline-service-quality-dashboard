# ✈️ Airline Service Quality Dashboard

An interactive Power BI dashboard built to analyze airline passenger satisfaction and identify the key factors affecting customer experience.

---

## Project Overview

This project analyzes airline passenger feedback to uncover insights into customer satisfaction, service quality, travel class performance, and flight delays using Microsoft Power BI.

The dashboard enables users to explore data interactively through filters, KPIs, charts, and advanced analytical visuals.

---

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Power BI Visualizations

---

## Features

- Overall Satisfaction KPI
- Average Arrival Delay
- Average Departure Delay
- Satisfaction Breakdown
- Customer Type Analysis
- Travel Class Analysis
- Service Rating Comparison
- Key Influencers
- Decomposition Tree
- Interactive Slicers

---

## Key Insights

- Business class passengers have higher satisfaction.
- Loyal customers report better experiences.
- Seat comfort and inflight service significantly impact satisfaction.
- Flight delays reduce customer satisfaction.
- Service quality is a stronger predictor of satisfaction than demographics.
